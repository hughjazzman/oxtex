\section{Introduction}
As mentioned in the previous chapter, classical simulation of quantum circuits provides an essential tool 
for verification and validation, despite its inherent limitations. 
This chapter delves into the methods and advancements in classical simulation 
via stabiliser decomposition, discussing the role of magic states, cat states, and graph cuts, 
in extending the capabilities of these simulations.
Classical simulation methods that store a complete description of an $n$-qubit quantum state 
as a complex vector of size $2^n$ are effective only for a small number of qubits, typically around 30. 
For example, Shor's factoring algorithm has been simulated with 31 qubits 
and approximately half a million gates \cite{wecker2014liquisoftwaredesignarchitecture}. 
However, for certain classes of quantum circuits, such as those that can be represented in a Clifford diagram, 
classical simulation can be significantly more efficient \cite{gottesman1998}. 
This is known as the \textit{Gottesman-Knill theorem}.

\begin{theorem}[Gottesman-Knill Theorem]
    \label{thm:gottesman-knill}
    A Clifford computation can be efficiently classically simulated.
\end{theorem}

In other words, a computation involving only \textit{Clifford diagrams} 
can be efficiently classically simulated.
This is extremely useful when considering that ZX-Calculus 
simplifies the process of identifying and manipulating \textit{stabiliser states}.

\begin{definition}[Stabiliser state \cite{Bravyi_2016bss,gottesman1998}]
    \label{def:stabiliser-state}
    An $n$-qubit state \ket{\psi} is a \textit{stabiliser state} if it has the form 
    \ctikzfig{stab_state}
    where $V$ is a Clifford diagram.
\end{definition}

It is clear that if a computation only involves stabiliser states,
then it can be efficiently classically simulated.
Stabiliser circuits are particularly notable for their applications in quantum error correction \cite{gottesman1998}. 
In the next few sections, we will see more clearly how these stabiliser states are used in classical simulation.
Particularly, we also need to consider Clifford+T diagrams,
and how we can still (inefficiently) simulate them using stabiliser states.


\section{Strong Simulation}

When simulating quantum circuits, 
we assume that the input state to our $n$-qubit circuits is of the form

\begin{equation}
\label{eq:input-state}
\cbox{\redbasisspider}^{\otimes n} :=
\left.\begin{matrix}
    \redbasisspider \\
    \redbasisspider \\
    \vdots \\
    \redbasisspider
\end{matrix} \right\} n
\end{equation}

Given that we have a $n$-qubit circuit with the input state from (\ref{eq:input-state}), 
we would then want to obtain the probability of measuring a certain output state.
For instance, we can plug in the outputs $\bra{\vec{x}}$ for $\vec{x}=x_1,x_2,...,x_n$ 
as spiders as in \autoref{fig:amplitude}.

\begin{figure}[h!]
    \[\tikzfig{amplitude} \in \C\]
    \caption{Scalar involving Clifford+T diagram $V$}
    \label{fig:amplitude}
\end{figure}

Then using the \hyperref[eq:born-rule]{Born rule}, 
we can obtain the probability of measuring the output state \cite{Kissinger2024}.

\begin{equation}
\label{eq:prob-all}
\Pr(x_1,x_2,...,x_n) = \frac{1}{\sqrt{2^{4n}}} \tikzfig{prob_all}
\end{equation}

$V^{\dagger}$ is used to denote the adjoint of $V$, which simply means the inputs and outputs are swapped,
and the spider phases are negated.
The scalar factors of $1/\sqrt{2}$ comes from those seen in (\ref{eq:spider-basis}).
If $V$ is a Clifford diagram, then following from the \nameref{thm:gottesman-knill}, 
the scalars can be computed efficiently.
Obtaining the probabilities this way is known as \textit{strong simulation}.

Marginal probabilities can also be obtained similarly.
Recall that using the law of total probability, we have for $k < n$,

\begin{equation}
    \label{eq:total-prob}
    \Pr(x_1,x_2,...,x_k) = \sum_{x_{k+1},x_{k+2},...,x_n} \Pr(x_1,x_2,...,x_k,x_{k+1},...,x_n)
\end{equation}

Then, applying the (\ref{eq:total-prob}) to (\ref{eq:prob-all}), and using the $\IdRule$dentity rule, where

\begin{equation}
    \sum_{x} \cbox{\copoint{x} \point{x}} \eqrule{\IdRule} \cbox{\idwire}
\end{equation}
we can obtain the marginal probabilities.

\begin{equation}
    \Pr(x_1,x_2,...,x_k) = \frac{1}{2^{n+k}} \tikzfig{prob_marginal}
\end{equation}

A natural question that arises is whether the same can be done if $V$ is a Clifford+T diagram instead.
The following sections will delve into the methods used to simulate such circuits.

\section{Stabiliser Decomposition}

\begin{definition}[Magic state \cite{Bravyi_2016bss}]
    \label{def:magic-state}
    The \textit{magic state} is 
    \[\cbox{\magicspider} 
    = \frac{1}{\sqrt{2}} \left( 
        \cbox{\redbasisspider} + e^{i\frac{\pi}{4}} \cbox{\redpibasisspider} 
    \right)\]
\end{definition}

The naïve approach to make use of this magic state decomposition is to then apply it 
to every single $T$-like spider in the Clifford+T diagram, 
where we define a $T$-like spider as a spider with a phase of $(2k+1)\frac{\pi}{4}$ for some $k\in\mathbb{Z}$.
By un$\SpiderRule$using the magic state from these spiders as below, 
we can apply the \nameref{def:magic-state} decomposition to obtain a sum of stabiliser states.

\begin{equation}
\tikzfig{magic_unfuse}
\end{equation}

This sum can be called the \textit{stabiliser decomposition} of the circuit.

\begin{definition}[Stabiliser Decomposition \cite{Bravyi_2016bss}]
    \label{def:stabiliser-decomposition}
    The \textit{stabiliser decomposition} of a state \ket{\psi} is a sum of stabiliser states
    \[\cbox{\npoint{\psi}} = \sum_{i=1}^n \lambda_i \cbox{\npoint{\psi_i}}\]
    where $\lambda_i \in \C$ and $\ket{\psi_i}$ are stabiliser states.
\end{definition}

More generally, a decomposition need not consist only of stabiliser states.

\begin{definition}[Decomposition]
    \label{def:decomposition}
    The \textit{decomposition} of a state \ket{\psi} is a sum of states
    \[\cbox{\npoint{\psi}} = \sum_{i=1}^n \lambda_i \cbox{\npoint{\psi_i}}\]
    where $\lambda_i \in \C$ and $\ket{\psi_i}$ are states.
    For any decomposition $d$, define its length to be $|d|=n$.
\end{definition}

Using the \nameref{def:magic-state} decomposition, we can see that the value of $n=2^t$
if we apply it to the $t$ $T$-like spiders in the circuit. 
We can call $t$ the \textit{T-count} of the circuit.

However, there is an even better decomposition 

\begin{equation}
\label{eq:magic2}
\begin{matrix}
\magicspider \\
\magicspider
\end{matrix}
=\tikzfig{magic2}
\end{equation}

This allows us to decompose the circuit into a sum of stabiliser states with $n=2^{\frac{t}{2}}$.
Different methods of decomposing the circuit can lead to different values of $n$.
Since $n$ is believed to be exponential in $t$ (or else we have $P=NP$) \cite{Bravyi_2019},
we can take it that $n=O(2^{\alpha t})$ for some $0<\alpha<1$.
We can then compare the efficiency of different methods by using this metric.

\begin{definition}[(In)efficiency \cite{Bravyi_2016bss,Bravyi_2016,Kissinger_2022,Kissinger2022cat}]
    \label{def:efficiency}
    The \textit{(in)efficiency} of a decomposition $D$ that reduces the $T$-count by $r$ 
    using $p$ states is
\begin{equation}
    \alpha(D) := \frac{\log_2(p)}{r}
\end{equation}
    where a lower value of $\alpha$
    \footnote{We omit $D$ when the context is clear} 
    indicates a more efficient decomposition.
\end{definition}

For example, the Bravyi-Smith-Smolin (BSS) decomposition \cite{Bravyi_2016bss} makes use of 
the following decomposition which has $\alpha \approx 0.468$.

\begin{equation}
    \label{eq:bss_decomp}
    \tikzfig{bss_decomp}
\end{equation}

Using this metric, we can even compare the efficiency of different algorithms used to decompose the circuit.
It also allows us to obtain the efficiency of different decompositions which do not use magic states at all.
As we will see in the next few chapters, this ties in well when we consider 
the higher efficiency of \textit{cat state} decomposition.

A closely related metric we can use is the \textit{stabiliser rank}.

\begin{definition}
    Let $D$ be the set of all stabiliser decompositions of a state \ket{\psi}.
    The \textit{stabiliser rank} $\chi(\ket{\psi})$ of a state \ket{\psi} is 
    \[\chi(\ket{\psi}) := 
    \min \{ n \mid \exists (d_1, d_2,...,d_n)\in D \text{ s.t. } \ket{\psi} = \sum_{i=1}^n d_i\}\]
\end{definition}

We can see that the relation between the stabiliser rank and its efficiency is
\begin{equation}
    \chi(\ket{\psi}) = 2^{\alpha_{\chi}(\ket{\psi}) t}
\end{equation}
with the $T$-count $t$ of the circuit.

The goal for any stabiliser decomposition is to obtain an efficiency as close to $\alpha_{\chi}$ as possible.

\section{Cat States}

\begin{definition}[Cat state \cite{Qassim_2021}]
    A \textit{cat state} is defined as
    \begin{equation}
        \cbox{\npoint{cat_n}} := \frac{1}{\sqrt{2}} \tikzfig{cat-state}
    \end{equation}
\end{definition}

Cat states are used because their decompositions have low value of $\alpha$,
as well as the following proposition, which bounds the $\alpha$ of the corresponding magic state decomposition.

\begin{proposition}
    Suppose $\alpha_1,\alpha_2$ are the efficiency metrics of the decompositions of 
    \[\left.\cbox{\npoint{cat_n}}\right\} n \quad\quad, \quad\quad 
    \left. \begin{matrix}
        \magicspider \\
        \magicspider \\
        \vdots \\
        \magicspider
    \end{matrix} \right\} n\]
    respectively. Then
    \[\alpha_1 \leq r \implies \alpha_2 \leq r + \frac{1}{n}\]
\end{proposition}

\begin{proof}
    The proof is adapted from \cite{Qassim_2021}.
    Suppose $\alpha_1 \leq r$.
    First, we show the following equality.
\begin{equation}
    \label{eq:lemma_TT}
    \tikzfig{lemma_TT}
\end{equation}
Then we can show the following.
\begin{equation}
    \tikzfig{prop_bounda}
\end{equation}
There are 2 copies of $\catstate{n}$ which would each give at most $2^{n\alpha_1}$ stabiliser states,
for a total of at most $2^{n\alpha_1 + 1}$ stabiliser states.
Thus, we have
\[\alpha_2 \leq \frac{n\alpha_1 + 1}{n} \leq r + \frac{1}{n}\]

\end{proof}

\section{Graph Cuts}

In a complementary approach to reducing the effective $\alpha$ of the stabiliser decomposition, 
graph cuts offer a different perspective \cite{Codsi2022}.
Suppose we have 2 Clifford+T diagrams $S_1, S_2$ of $T$-counts $t_1,t_2$ that both 
have a stabiliser decomposition efficiency of $\alpha$.

\begin{equation}
    \tikzfig{graph_cut_ex}
\end{equation}

If we combine the diagrams into a single diagram $S$,
we could expect the stabiliser decomposition efficiency of $S$ to be $\alpha$,
coming from having $2^{\alpha(t_1+t_2)}$ stabiliser states.
However, since we can treat $S_1,S_2$ independently and multiply their stabiliser decompositions,
the actual number of stabiliser states is instead $2^{\alpha t_1} + 2^{\alpha t_2} \leq 2^{\alpha t + 1}$,
where $t=\max(t_1,t_2)$.
This gives a resulting $\alpha' \leq \alpha \frac{t + 1}{t_1+t_2}$.
In the ideal case, we have that $t_1=t_2$, so $\alpha' \leq \frac{\alpha}{2} + \frac{1}{2t}$, 
a vast improvement especially for a high $T$-count.
It is with this motivation that graph cuts are another promising approach.

First, by definition, we can see that 
\begin{equation}
    \label{eq:spider-cut}
    \tikzfig{spider_decomp_abs}
\end{equation}
Note that while this decomposition \CutRule is not necessarily on a state,
because of OCM, and the use of cups and caps, we can easily consider this to fit 
the definition of a \nameref{def:decomposition}. 

Then if we have a diagram with subdiagrams $S_1,...,S_n$, we can see that the following holds.

\begin{equation}
    \label{eq:mcuts}
    \tikzfig{mcuts}
\end{equation}

At the cost of $m$ cuts, and thus $2^m$ terms, 
the diagram is split into $\leq m^2 + n$ subdiagrams that can be treated independently.
The $\leq m^2$ scalars in the form of spider-pairs are trivially scalars (\ref{eq:scalars}),
and there are only $\leq n$ subdiagrams with $T$-counts $>0$.
If each subdiagram $S_i$ has the $T$-count of $t_i$,
we have a sum of $2^m$ terms, each value which can be obtained with just $\leq m^2 + \sum_{i=1}^n 2^{\alpha t_i}$ stabilizer terms.
This gives a total of $\leq 2^m(m^2 + \sum_{i=1}^n 2^{\alpha t_i})$ stabilizer terms.
We can obtain the efficiency.
\begin{equation}
\begin{aligned}
    \alpha' &\leq \frac{\log_2 (2^m(m^2 + \prod_{i=1}^n 2^{\alpha t_i}))}{\sum_{i=1}^n t_i}\\
    &= \frac{m + \log_2(m^2 + \prod_{i=1}^n 2^{\alpha t_i})}{\sum_{i=1}^n t_i}\\
    &\leq \frac{m + 2\log_2(m) + \sum_{i=1}^n \alpha t_i}{\sum_{i=1}^n t_i}
\end{aligned}
\end{equation}

In the ideal case where $t_i=t$ for all $i$, we can produce a crude upper bound
\begin{equation}
\begin{aligned}
    \alpha' &\leq \frac{\alpha}{n} + \frac{m + \log_2(m^2 n)}{nt}\\
    &< \frac{\alpha}{n} + \frac{3m + n}{nt}\\
    &= \frac{\alpha}{n} + \frac{3m}{nt} + \frac{1}{t}
\end{aligned}
\end{equation}
Keeping the ratio $m/n$ small is key to reducing the effective $\alpha$.
Clearly, fewer cuts are better, with preferably the end result being many disconnected subdiagrams.

Another way graph cuts also reduce the effective $\alpha$ need not necessarily 
be by obtaining disconnected subdiagrams.
On pseudo-structured circuits produced from CNOTs, phase gates, and Toffolis,
graph cuts were used to take advantage of the structure to optimise for the use of
spider $\SpiderRule$usion in cascading fashion, 
where a single cut can lead to a large reduction in the $T$-count \cite{sutcliffe2024proccut}. 
There, the effective efficiency obtained was $0.1 \lesssim \alpha \lesssim 0.2$.
More details on this will be discussed in \autoref{sec:graph-cut}.

The same was also found for extremely structured circuits involving cat states,
where a single decomposition reduced the $T$-count by 286, for an $\alpha \approx 0.0035$ \cite{Codsi2022},
though this was an ideal case which is unlikely to occur in practice.

\section{Subgraph Complement}

A further addition to the strength of graph cuts is the subgraph complement approach.
For a graph-like ZX-diagram $(V, E)$, with $K$ being the set of edges for a complete graph on $V$,
its \textit{complement} is simply $(V, K \backslash E)$.
We define a \textit{subdiagram} to simply be a subgraph of the graph-like ZX-diagram.
If we analyse \LCRule closely, and consider the Hopf rule \HopfRule making parallel edges cancel,
there seems to be a way to obtain a subgraph complement with some manipulation of ZX-rules.
In fact, we have the following result.

\begin{proposition}[\cite{Codsi2022}]
    \label{prop:subgraph_complement}
    Suppose we have a subdiagram $S$ of a graph-like ZX-diagram. Then
\begin{equation}
    \label{eq:subgraph_complement}
    \cbox{\boxdiag{S}} \approx \cbox{\boxdiag{\bar{S}^+}} + i\cbox{\boxdiag{\bar{S}^-}}
\end{equation}
    where $\bar{S}^+,\bar{S}^-$ are the complements of $S$ where the spider phases differ from $S$
    by $\pm\frac{\pi}{2}$ respectively.
\end{proposition}
